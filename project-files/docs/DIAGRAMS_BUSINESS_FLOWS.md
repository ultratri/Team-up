# 🔄 Team Up 业务流程图

## 1. 用户注册流程

```mermaid
graph TD
    A["用户访问注册页面"] --> B["填写注册信息"]
    B --> C["验证邮箱"]
    C --> D{邮箱验证成功?}
    D -->|否| E["重新发送验证码"]
    E --> C
    D -->|是| F["创建用户账户"]
    F --> G["初始化用户资料"]
    G --> H["设置初始信誉分 = 50分"]
    H --> I["标记为新手用户"]
    I --> J["发送欢迎邮件"]
    J --> K["跳转到完善资料页面"]
    K --> L["注册完成"]
    
    style A fill:#e1f5ff
    style L fill:#c8e6c9
```

## 6. 信誉分更新流程

```mermaid
graph TD
    A["项目完成评价"] --> B["收集所有评价"]
    B --> C["计算项目评价分"]
    C --> D["获取用户当前信誉分"]
    D --> E["应用更新公式"]
    E --> F["新信誉分 = 旧信誉分 × 0.7 + 项目评价分 × 0.3"]
    F --> G["检查信誉等级变化"]
    G --> H{等级是否变化?}

    H -->|否| J["保持原等级"]
    I --> K["发送升级通知"]
    J --> K
    K --> L["信誉分更新完成"]

```

## 7. 新手保护流程

```mermaid

    H3 --> I
    H4 --> I

```
