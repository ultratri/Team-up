## 1. 学生角色定义

### 1.1 角色特征

**学生（STUDENT）** 是系统的主要用户群体，具有以下特征：

```
身份定位：
├── 项目创建者：发起项目，招募团队成员
├── 项目参与者：申请加入他人项目
├── 团队成员：参与团队协作
├── 技能学习者：通过项目提升技能
└── 社交参与者：关注他人，收藏项目

核心需求：
├── 找到合适的项目和队友
├── 展示自己的技能和经验
├── 参与团队协作完成项目
├── 积累项目经验和信誉
└── 参加比赛获得成长
```

### 1.2 权限范围

| 功能模块 | 权限说明 |
|---------|---------|
| 个人资料 | ✅ 完整编辑权限 |
| 项目创建 | ✅ 可创建项目 |
| 项目申请 | ✅ 可申请加入项目 |
| 团队管理 | ✅ 管理自己创建的团队 |
| 任务协作 | ✅ 团队内任务管理 |
| 文件共享 | ✅ 团队内文件管理 |
| 消息通信 | ✅ 团队聊天和私信 |
| 比赛查看 | ✅ 查看所有已发布比赛 |
| 评价他人 | ✅ 项目完成后互评 |
| 数据统计 | ⭕ 仅查看自己的数据 |

<script setup lang="ts">
import { ref, reactive, computed } from 'vue';
import { useRouter } from 'vue-router';
import { ElMessage } from 'element-plus';
import { register } from '@/api/auth';
import { departmentMajorMap } from '@/utils/departmentMajorPreset';

const router = useRouter();
const currentStep = ref(0);
const registering = ref(false);

const form = reactive({
  studentId: '',
  username: '',
  email: '',
  password: '',
  confirmPassword: '',
  realName: '',
  department: '',
  major: '',
  grade: null,
  phone: '',
  agreeToTerms: false
});

const departments = Object.keys(departmentMajorMap);
const majors = computed(() => {
  return form.department ? departmentMajorMap[form.department] : [];
});

const rules = {
  studentId: [
    { required: true, message: '请输入学号/工号', trigger: 'blur' },
    { pattern: /^[0-9]{8,12}$/, message: '学号格式不正确', trigger: 'blur' }
  ],
  username: [
    { required: true, message: '请输入用户名', trigger: 'blur' },
    { min: 2, max: 20, message: '用户名长度为2-20个字符', trigger: 'blur' }
  ],
  email: [
    { required: true, message: '请输入邮箱', trigger: 'blur' },
    { type: 'email', message: '邮箱格式不正确', trigger: 'blur' }
  ],
  password: [
    { required: true, message: '请输入密码', trigger: 'blur' },
    { min: 8, max: 20, message: '密码长度为8-20个字符', trigger: 'blur' },
    { 
      pattern: /^(?=.*[A-Za-z])(?=.*\d)[A-Za-z\d@$!%*#?&]/, 
      message: '密码需包含字母和数字', 
      trigger: 'blur' 
    }
  ],
  confirmPassword: [
    { required: true, message: '请确认密码', trigger: 'blur' },
    { 
      validator: (rule, value, callback) => {
        if (value !== form.password) {
          callback(new Error('两次输入的密码不一致'));
        } else {
          callback();
        }
      }, 
      trigger: 'blur' 
    }
  ],
  realName: [
    { required: true, message: '请输入真实姓名', trigger: 'blur' }
  ],
  department: [
    { required: true, message: '请选择院系', trigger: 'change' }
  ],
  major: [
    { required: true, message: '请选择专业', trigger: 'change' }
  ],
  grade: [
    { required: true, message: '请选择年级', trigger: 'change' }
  ],
  agreeToTerms: [
    { 
      validator: (rule, value, callback) => {
        if (!value) {
          callback(new Error('请阅读并同意用户协议'));
        } else {
          callback();
        }
      }, 
      trigger: 'change' 
    }
  ]
};

const step1Form = ref(null);
const step2Form = ref(null);
const step3Form = ref(null);

const nextStep = async (step: number) => {
  let formRef;
  if (step === 1) formRef = step1Form.value;
  else if (step === 2) formRef = step2Form.value;
  
  if (formRef) {
    await formRef.validate((valid) => {
      if (valid) {
        currentStep.value = step;
      }
    });
  }
};

const prevStep = () => {
  currentStep.value--;
};

const handleDepartmentChange = () => {
  form.major = '';
};

const handleRegister = async () => {
  await step3Form.value.validate(async (valid) => {
    if (!valid) return;
    
    registering.value = true;
    try {
      const res = await register({
        studentId: form.studentId,
        username: form.username,
        email: form.email,
        password: form.password,
        realName: form.realName,
        department: form.department,
        major: form.major,
        grade: form.grade,
        phone: form.phone,
        role: 'STUDENT'
      });
      
      ElMessage.success('注册成功！');
      
      // 保存token
      localStorage.setItem('token', res.token);
      
      // 跳转到完善资料页面
      router.push('/profile/complete');
    } catch (error) {
      ElMessage.error(error.message || '注册失败，请重试');
    } finally {
      registering.value = false;
    }
  });
};

const showTerms = () => {
  // 显示用户协议
};

const showPrivacy = () => {
  // 显示隐私政策
};
</script>

### 3.2 完善个人资料

**路由：** `/profile/complete`

**引导流程：**

新用户注册后，系统会引导完善以下信息：

1. **基础信息**（必填）
   - 上传头像
   - 填写个人简介
   - 添加联系方式（微信、QQ）

2. **技能标签**（必填，至少3个）
   - 选择技能分类
   - 添加技能名称
   - 设置熟练度

3. **时间可用性**（可选）
   - 设置每周空闲时间
   - 帮助系统推荐时间匹配的项目

4. **兴趣方向**（可选）
   - 选择感兴趣的项目类型
   - 选择感兴趣的比赛

**页面实现：**

      </div>
      
      <el-steps :active="currentStep" align-center
