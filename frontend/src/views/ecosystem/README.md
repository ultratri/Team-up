# 生态广场（综合广场）

## 功能概述

生态广场是一个统一的入口，整合了项目、人才、比赛、资源和动态等多个模块，为用户提供一站式的浏览和发现体验。

## 模块说明

### 1. 项目大厅 (ProjectHall)
- **功能**：展示所有招募中和进行中的项目
- **特色**：
  - 新手友好标签
  - 急需成员标签
  - 匹配度评分（基于用户技能）
  - 项目类型筛选
  - 项目状态筛选

### 2. 人才广场 (TalentSquare)
- **功能**：展示平台上的活跃用户，支持双向匹配
- **特色**：
  - 新人标识
  - 导师标识
  - 技能标签展示
  - 完成项目数和信誉分展示
  - 院系和技能筛选

### 3. 赛事中心 (CompetitionCenter)
- **功能**：展示所有比赛信息
- **特色**：
  - 比赛级别标签（校级、省级、国家级、国际级）
  - 即将截止提醒
  - 报名时间展示
  - 参赛队伍数量统计

### 4. 资源广场 (ResourceSquare)
- **功能**：展示项目成果、技术文档、面经分享等资源
- **特色**：
  - 资源类型分类
  - 浏览量和点赞数统计
  - 封面图展示
  - 技术标签

### 5. 动态广场 (MomentSquare)
- **功能**：展示用户的关键活动动态
- **特色**：
  - 创建项目动态
  - 加入项目动态
  - 完成项目动态
  - 获得徽章动态
  - 点赞和评论功能

## 设计理念

### 统一的视觉风格
- 参考导师广场的设计风格
- 使用渐变背景和光球装饰
- 卡片式布局，支持悬停动画
- 响应式设计，适配移动端

### 全局搜索
- 支持跨模块搜索
- 搜索项目、人才、比赛、资源

### 统计数据展示
- 活跃项目数
- 在线人才数
- 进行中比赛数

## 技术实现

### 组件结构
```
EcosystemHub.vue (主页面)
├── tabs/
│   ├── ProjectHall.vue (项目大厅)
│   ├── TalentSquare.vue (人才广场)
│   ├── CompetitionCenter.vue (赛事中心)
│   ├── ResourceSquare.vue (资源广场)
│   └── MomentSquare.vue (动态广场)
```

### 路由配置
- 路径：`/ecosystem`
- 名称：`EcosystemHub`
- 权限：无需登录即可访问（部分功能需要登录）

### 状态管理
- 使用 Vue 3 Composition API
- 响应式数据管理
- 异步数据加载

## 后续开发计划

### 短期（1-2周）
1. 实现后端API接口
2. 完善人才广场的用户数据展示
3. 实现资源广场的资源上传和管理
4. 实现动态广场的动态发布和互动

### 中期（1个月）
1. 实现智能匹配算法
2. 实现全局搜索功能
3. 添加推荐系统
4. 优化性能和用户体验

### 长期（2-3个月）
1. 实现组队实验室功能
2. 实现任务/悬赏广场
3. 添加数据可视化
4. 完善社交功能

## 注意事项

1. **数据一致性**：确保各模块数据与原有页面保持一致
2. **权限控制**：部分功能需要登录后才能使用
3. **性能优化**：使用分页加载，避免一次性加载大量数据
4. **响应式设计**：确保在移动端也能正常使用
